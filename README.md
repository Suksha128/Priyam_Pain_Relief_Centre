## ✨ Website Features & Design Architecture

- **Golden Shining Borders**: Metallic gradient borders (`#B38728` to `#FCF6BA`) with an animated light-sweep sheen and ambient warm drop-shadows.
- **Earthy Warm Aesthetics**: Warm ivory and soft cream parchment canvas complemented by bamboo emerald green accents.
- **Dedicated Benefit Sections**:
  - Separate detailed section for **Acupuncture Benefits** (endorphin stimulation, pain-gate modulation, non-toxic drug-free healing).
  - Separate detailed section for **Zero-Gravity Massage Chair** (with rate cards, stress relief, posture correction, and energy recharge).
  - Separate detailed section for **Foot Massage & Reflexology** (with plantar organ map, neuropathy relief, and lymphatic drainage).
- **Interactive Conditions Treated Directory**: Search and filter cards for Migraine, Arthritis, Insomnia, Sinusitis, Infertility, Menstrual Problems, Varicose Veins, Liver/Gallbladder, Obesity, and more.
- **Contrasting Bottom Section**: Majestic deep royal obsidian emerald (`#0A1711`) background highlighting the clinic address, Google Map embed, direct driving directions, and visiting hours.
- **Online WhatsApp Booking Modal**: Captures patient name, phone, chosen therapy, preferred date and time slot (10 AM - 7 PM), and generates a pre-formatted WhatsApp booking message.
- **Floating WhatsApp Quick Chat**: Persistent one-click chat button on all screen sizes.

## 🚀 Local Development & Preview

To run the website locally on your computer:

```bash
# Navigate to the project directory
cd /Users/sukshas/.gemini/antigravity/scratch/Priyam_Pain_Relief_Centre

# Start a local Python HTTP server
python3 -m http.server 8080
```

Open your browser and navigate to `http://localhost:8080`.

## 🌐 GitHub Pages Deployment

To host this site live on GitHub Pages:
1. Go to repository settings on GitHub: `https://github.com/suksha128/Priyam_Pain_Relief_Centre/settings/pages`
2. Under **Build and deployment** &gt; **Branch**, select `main` (root) and click **Save**.
3. Your website will be live in 1-2 minutes at:
   `https://suksha128.github.io/Priyam_Pain_Relief_Centre/`
